# Google Cybersecurity Portfolio

Portfolio projects completed during the Google Cybersecurity Professional Certificate program, covering incident response, network analysis, threat investigation, security documentation, and security operations.

## Additional incident response labs

### [25 — Suspicious VPN Login Investigation](./25-Incident-Response-Lab-01-Suspicious-VPN-Login/README.md)

A fictional, scenario-based incident response case study covering authentication log triage, potential credential attacks, MFA verification, VPN session investigation, proportionate containment, evidence gaps, incident documentation, and preliminary MITRE ATT&CK mapping.

> This is a self-directed educational simulation using fictional data. It is not professional incident-response experience or hands-on work in a production SIEM.

### [26 — Suspicious Benefits Email Investigation](./26-Incident-Response-Lab-02-Suspicious-Phishing-Email/README.md)

A fictional phishing triage exercise covering email headers and authentication results, safe URL analysis, IoCs, preliminary MITRE ATT&CK mapping, severity assessment, response recommendations, and a concise incident report. The scenario uses inert training data and makes no claim of production experience.
